# VLSI Fundamentals and Digital Logic Design

> **Task 1 Submission – Maincrafts Technologies VLSI Design Internship**

## Overview

This repository showcases the successful completion of **Task 1** for the **Maincrafts Technologies VLSI Design Internship**. The task focused on building a strong foundation in **Very Large Scale Integration (VLSI)** by exploring digital logic concepts and implementing fundamental combinational circuits using **Logisim**.

The repository combines theoretical understanding with practical circuit design, simulation, and verification.

## Objectives

- Develop a clear understanding of VLSI technology and its real-world applications.
- Study the standard VLSI design methodology.
- Learn the fundamentals of digital logic design.
- Design and simulate basic logic gates using Logisim.
- Implement and verify combinational circuits through simulation.

## Topics Covered

### VLSI Fundamentals
- Introduction to VLSI
- Applications of VLSI
- VLSI Design Flow

### Digital Logic
- Boolean Logic
- Logic Gates
  - AND
  - OR
  - NOT
  - NAND
  - NOR
  - XOR

### Combinational Circuit Design
- Half Adder
- Full Adder
- Half Subtractor
- Full Subtractor
